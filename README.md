# ONX 暖玻璃 (ONX Warm Glass)

一款基于 [Border](https://github.com/Akifyss/obsidian-border) 二次开发的 Obsidian 暗色主题 —— 暖调半透明玻璃:暖色底 + 顶部微光 + 细描边 + 柔和投影。

> ⚠️ **仅支持暗色模式**:亮色模式未做适配,请勿切到亮色使用。

## 特性

- 🌅 **暖玻璃视觉**:菜单、弹窗、侧栏、代码块统一为暖调半透明玻璃卡片
- 🎨 **代码块重绘**:语法色映射到 Border 的标题色阶,代码面板为浮起的暖玻璃卡片
- 🧩 **全套 UI 覆盖**:设置弹窗、命令面板、菜单、Callout、嵌入、属性面板、文件树、标签栏、状态栏
- 🔧 **保留 Border 全部 Style Settings 选项**,可继续自由调节

## 安装

**方式一:手动安装**

1. 下载本仓库的 `theme.css` 与 `manifest.json`;
2. 放入你的仓库:`.obsidian/themes/ONX 暖玻璃/`;
3. Obsidian 设置 → 外观 → 主题,选择「ONX 暖玻璃」。

**方式二:BRAT**

1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件;
2. 使用「Add Beta theme」添加本仓库地址。
